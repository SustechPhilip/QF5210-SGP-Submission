**这 15 天全部从 08:30 一直交易到当期收盘（17:14 或 17:19），没有一天提前收盘**
（逐日核对 `D_last_hm` 与当期规则末根，全部一致）。它们不是半日市，分钟数少是因为
**很多分钟没有成交**：这些日期基本是新加坡股票市场休市或半日市的日子（耶稣受难日、圣诞节、
节礼日、平安夜与除夕下午、农历新年），现货不开或只开半天，期货没有现货指数可以跟，
成交变得很稀。

**v1 和 v2 里"半日市""354/359 分钟"的措辞全部删除**——那是把"稀疏"误读成"提前收盘"。

**处理规则**：

- 这些天 17:00 决策、收盘时执行**依然成立**，不存在"收盘早于决策时点"的问题。
- 保留在交易日历中（否则持仓盈亏错位）。
- **B 类日内因子在该日置 NaN**，这些行不进训练样本。
- 预测该日时，缺失的 B 类因子用**前一个交易日的值**（as-of 规则）填充。

**v2 规则**：稀疏日判定改为**决策窗相对阈值**（第二轮复核修正第 4 条：只用 ≤16:59 的 bar，
判定「今天数据够不够用」时不看 17:00 之后的信息；决策窗 08:30–16:59 固定 510 根，
四个交易规则时期都一样，因此与时期无关）

```python
dec_bars    = day[day.hm <= "16:59"].groupby("td").size()      # 决策窗内 bar 数
thin_day    = (dec_bars < 0.85 × 510)                          # 阈值与期望都来自 config
data_gap    = 决策窗内连续无成交 >= 60 分钟                     # 阈值来自 config
```

命中 **15 天**（上表全部）。改用决策窗口径后命中的日期与原全日口径**完全相同（0 处分歧）**。

**`data_gap`：2024-11-25 单列。** 这天不是新加坡假日，但盘中 13:36 → 15:45 有 **128 分钟
连续空白**（跨度 129 分钟），其余时段正常交易到 17:19，像是数据中断或交易暂停。
单列为 `data_gap = 1`，报告里单独列出。`thin_day` 与 `data_gap` 是两个独立标记：
2024-11-25 同时命中两者。

`daily_full.csv` 原有的 `short_day` 列保留但被 `thin_day` 取代，最终交付前 patch `daily.py`，
同时新增 `thin_day`、`data_gap` 两列。

## 2. 未来函数防线

### 2.1 两张表的硬约束

因子函数**只能**读这两样东西：

```python
feat_t = f(dec.loc[:t], full.shift(1).loc[:t])
```

- `dec`（`daily_dec.csv`）：t 日夜盘（已结束的夜盘）+ t 日日盘 ≤16:59。
- `full.shift(1)`：t−1 日完整日盘（含 t−1 的收盘价与尾盘）。
- `daily_full.csv` 的**当日行禁止进入任何因子路径**（含描述性统计）。
- §1.5 的"复核版"概念取消，`daily_full.csv` 只以 `shift(1)` 形式出现。

### 2.2 标签已知时间（v1 漏掉，会造成隐蔽未来函数）

`labels.csv` 的 `y_cc[t] = C_{t+1}/C_t − 1`，实现于 t+1 收盘（`y_cc_known_ts`）。
决策在 t 日 17:00，而 t 日的标签要到 t 日 17:15/17:20 收盘才实现，**决策时未知**。

统一规则（方案一、方案二共用）：

```python
label_known_ts[t] = 标签实现的时间戳
train_rows = rows[label_known_ts < decision_ts[t]]
```

代入 `y_cc_known_ts[t] = close_ts[t+1]`、`decision_ts[t] = t 17:00`：

- t−1 行标签的实现时间是 `close_ts[t]` = t 17:15（R0/R1）或 17:20（R2/R3）> t 17:00 → **不可用**。
- t−2 行标签的实现时间是 `close_ts[t−1]` < t 17:00 → **可用**。

所以 **t 日决策时，训练集最新可用行是 t−2**，特征与标签配对为 `(feat_s, y_cc[s])`，s ≤ t−2。
这在四个时期完全一致（`close_ts` 恒晚于同日 17:00），不需要分时期处理。

### 2.3 截断一致性测试（改写 v1 的错误单元测试）

v1 写的"把决策线从 16:59 挪到 16:30，因子值必须不变"**不可能通过**——因子本来就随截断点变化。
正确的测试：

随机抽 20 个日期 t：

1. 把分钟数据截到 `t 16:59:59`，从头重跑整条管线；
2. 与全量数据跑出的结果比较：`feat[t]`、`ŷ[t]`、`pos[t]` 必须 `np.allclose`，
   所有 < t 的行必须完全一致。

该测试在**因子模块完成时就跑通**，不拖到最后。

### 2.4 其余防线

- 标准化/截尾的分位数与均值，只用当期训练窗口内的数据算，再套到预测行。
- 净值与指标由**同一份** `R[t]` 序列生成；手算抽查 5 天（仓位→盈亏→成本链路）。
- 回测与每日自动更新用**同一份代码**，只换数据截止日。

## 3. 因子库

### 3.0 记号与数据来源

| 记号 | 含义 | 来源 |
|---|---|---|
| `C*_t` | t 日 16:59 日盘收盘价 | `dec.C_star` |
| `V*_t` | t 日日盘成交量（≤16:59） | `dec.d_vol` |
| `VWAP*_t` | t 日日盘成交量加权均价（≤16:59） | `dec.d_vwap` |
| `O_t` | t 日日盘开盘价 | `dec.d_open` |
| `DH_t`, `DL_t` | t 日日盘最高/最低（≤16:59） | `dec.d_high`, `dec.d_low` |
| `NO_t`, `NC_t` | t 日夜盘（共有窗口 17:50–04:44）开/收盘 | `dec.nc_open`, `dec.nc_close` |
| `NV_t` | t 日夜盘共有窗口成交量 | `dec.nc_vol` |
| `NRV_t` | t 日夜盘共有窗口已实现波动 | `dec.nc_rv` |
| `C_{t−1}` | t−1 日日盘最后一笔成交价 | `full.shift(1).C` |
| `VWAP^{17:05–17:14}_{t−1}` | t−1 日 17:05–17:14 的 VWAP | `full.shift(1).C_vwap_1705_1714` |
| `P_t(hh:mm)` | t 日 ≤ hh:mm 的最后一根 bar 的收盘价 | 分钟数据重算 |
| `r_i` | 相邻**在场** bar 之间的对数收益（缺失分钟视为无成交，不前值补价） | 分钟数据重算 |
| `ANN` | 年化系数，`= 交易日数 / 样本年数` ≈ 260 | 计算得到 |

**B 类因子需要分钟级重算**，`daily_dec.csv` 里没有对应字段。因子模块导入数据层的
`sgp/sessions.py` 得到带 `td`/`session` 标注的分钟表，再按上表口径聚合。正式交付时把
`sessions.py`/`daily.py` 从 zip 解到项目目录 `sgp_data/`，不依赖 `/tmp`。

### 3.1 A 类 趋势与动量（基准序列 `C*`，窗口 {1,5,20,60,120}）

| 编号 | 因子 | 公式 |
|---|---|---|
| A1 | `MOM_k` | `ln(C*_t / C*_{t−k})`，k ∈ {1, 5, 20, 60, 120} |
| A2 | `MOMVWAP_k` | `ln(VWAP*_t / VWAP*_{t−k})`，k ∈ {5, 20, 60} |
| A3 | `TS_k` | `(C*_t − MA_k(C*)) / sd_k(C*)`，k ∈ {20, 60} |
| A4 | `DC_k` | `(C*_t − min_k(C*)) / (max_k(C*) − min_k(C*))`，k ∈ {20, 60}（窗口含 t） |
| A5 | `MMS` | `(MA_5(C*) − MA_20(C*)) / C*_t` |
| A6 | `σ̂_60` | `sd_{60}(ln(C_s/C_{s−1})) × sqrt(ANN)`，s ≤ t−1（`full.shift(1)`） |

A1 恢复了 v1 删掉的 1 日收益；240/250 日窗口统一压到 120。
**A6 不作为模型特征**，只做波动率目标的分母（§5.3）。

### 3.2 B 类 日内价量（t 日日盘 ≤16:59 的分钟线）

| 编号 | 因子 | 公式 |
|---|---|---|
| B1 | `TAIL_n` | `ln(C*_t / P_t(16:59−n))`，n ∈ {5, 10, 30} |
| B2 | `VDEV` | `(C*_t − VWAP*_t) / VWAP*_t` |
| B3 | `SEG_AM` | `ln(P_t(12:00) / P_t(08:30))` |
| B3 | `SEG_NOON` | `ln(P_t(13:00) / P_t(12:00))` |
| B3 | `SEG_PM` | `ln(C*_t / P_t(13:00))` |
| B3 | `SEG_OPEN30` | `ln(P_t(09:00) / P_t(08:30))` |
| B4 | `RV` | `sqrt(Σ r_i²)` |
| B4 | `RVUP` / `RVDN` | `sqrt(Σ max(r_i,0)²)` / `sqrt(Σ max(−r_i,0)²)` |
| B4 | `UDRATIO` | `RVUP / RVDN` |
| B5 | `SKEW` / `KURT` | 分钟收益的偏度 / 超额峰度 |
| B6 | `VMOM1..4` | 分钟成交量的均值、标准差、偏度、超额峰度 |
| B7 | `UDVOL` | `Σ_{r_i>0} v_i / Σ_{r_i<0} v_i` |
| B8 | `PVCORR` | `corr(r_i, Δv_i)`，`Δv_i = v_i − v_{i−1}` |
| B9 | `HIGHT` / `LOWT` | 当日最高/最低价 bar 的时刻归一化到 [0,1]：`(时刻 − 08:30) / (16:59 − 08:30)` |
| B10 | `TAILVOL` | `Σ_{16:29 ≤ hm ≤ 16:59} v_i / V*_t`（分母用决策版） |
| B11 | `CLOSESETTLE` | `(C_{t−1} − VWAP^{17:05–17:14}_{t−1}) / VWAP^{17:05–17:14}_{t−1}`（研报对照口径，`full.shift(1)`） |
| B11 | `PRECLOSE` | `(C*_t − VWAP^{16:50–16:59}_t) / VWAP^{16:50–16:59}_t`（当日 pre-close 版，改名以免与研报尾盘混淆） |
| B12 | `TAIL15` | `ln(P_{t−1}(17:14) / P_{t−1}(17:00))`（`full.shift(1)`，固定时刻窗口，不写"最后 15 分钟"） |

## 4. 筛选与建模

### 4.1 单因子信号与方向（滚动外推 walk-forward，解决 v1"方向没定义"）

对每个因子 i，在**每个日期 t** 用 ≤t−2 的数据重新拟合（与 §2.2 同一条已知时间规则），
再预测 t：

```python
for t:
    rows = {s ≤ t−2, 样本内且标签已知}
    if len(rows) < MIN_TRAIN_SCREEN:  # 120
        continue                        # 该日不产生单因子信号
    a, b = OLS(y ~ f_i).fit(rows)
    ŷ_i,t = a + b * f_i,t
    s_i,t = clip(ŷ_i,t / sd(rows 内 ŷ_i), -1, 1)
Sharpe_i = 全部外推预测上的年化 Sharpe
```

**为什么必须外推而不是样本内拟合**：在训练窗内拟合系数 b、再在同一段数据上评估 `s_i·y`，
b 的符号本来就按这段数据的相关方向定，样本内 Sharpe 几乎必然 > 0。于是 **loose 档的
`Sharpe > 0` 阈值形同虚设，实际只剩相关性一道筛选**，主配置的筛选规则失效。
外推后 Sharpe 的符号才有意义，`Sharpe > 0` 才是真门槛。

- `MIN_TRAIN_SCREEN = 120`：训练段内约 **423 天**有外推样本（特征完整行 544 行减去 120 行预热）。
- 反转类因子自动得到负系数，不会被筛掉；类内等权时也不会正负抵消。
- `Sharpe_i` 按**扣默认成本**后的序列计算（§5.2），与最终回测同口径，研报也全程计费。
  副作用是偏向换手低的慢因子（A、C 类），报告里写一句。
- 报告中注明：筛选用的是**训练段内的外推**预测，不是样本内拟合值。

### 4.2 三档筛选（阈值出处分开标注）

| 档位 | Sharpe 阈值 | 相关性阈值 | 出处 | 原文样本外结果 |
|---|---|---|---|---|
| **loose（主）** | > 0 | < 0.2 | 系列 2 | 样本外 0.69 |
| strict_S2 | > 0.8 | < 0.2 | 系列 2 | 样本外 0.27 |
| strict_S3 | > 0.5 | < 0.3 | 系列 3 | — |

v1 把系列 2 的"0.69 对 0.27"拿去论证系列 3 的阈值，出处混了，已更正。

做法：按训练期 `Sharpe_i` 从高到低贪心纳入；相关性用训练期**因子值的 Spearman 相关**，
候选因子需与**所有**已入选因子的 |ρ| 都低于阈值。

### 4.3 RFE 与主结果登记（只在训练集做一次）

- 过程：反复在**训练集**上做 OLS，删除 |t 统计量| 最小的那个特征并重新拟合，直到剩
  `min(10, |S|)` 个。
- **特征集合全程固定**；之后每日只重估系数，不重选特征。
- 特征选择与 RFE 只用训练段（≤2022-12-31）数据，不碰验证期与测试期。
- 原计划"按季度重新选因子"今晚不做，在差异披露里写明。

**主结果预先登记**（避免看到结果后再选模型，破坏"只看一次测试集"）：

|---|---|
| 筛选 | loose（Sharpe > 0 外推、|ρ| < 0.2） |

### 4.4 标准化、截尾与打分

```python
μ, s, q01, q99 = 训练窗内的均值/标准差/1%/99%分位数
x_w = clip(x, q01, q99)
z   = (x_w − μ_w) / s_w                       # μ_w, s_w 为截尾后的训练均值/标准差

z_t = ŷ_t / sd(训练窗内模型的拟合值)
pos_raw = clip(z_t, -1, 1)
```

### 4.5 基准策略

- `buyhold`：**纯持有**，`pos ≡ 1`，**不做波动率缩放**（做了缩放仓位每天都在变，就不是买入持有了），
  只在建仓时收一次成本。
- `long_vt`：**常多 + 波动率目标**，`pos = 1 × min(1, target/σ̂_60,t)`，仓位随波动率变化。
- `mom20`：`pos = sign(MOM_20)`，经波动率目标缩放，计成本（v1 §3 的"20 日动量符号基准"）。
- 三个基准与 OLS/Ridge **同成本、同回测骨架**；`buyhold` 与 `long_vt` 的差别只在波动率缩放，
  这正是"买入持有"与"波动率目标下的常多"的对照。
- **测试期指标从 2024-01-01 重新建仓起算**：`buyhold` 在测试期起点收一次建仓成本，
  `long_vt` 同样从 0 建仓。

### 4.6 分类等权对照（降级为稳健性，可砍）

按你的砍单顺序，`cat_equal` 属于**可先砍**项，优先级低于主线。保留时的定义：

- 每个入选因子生成单因子信号 `s_i`（§4.1，滚动拟合）；
- 类内等权 → 类间等权（A/B/C/D/E 五类）；
- `pos = clip(类间均值, -1, 1)`；
- **等权的是信号，不是因子值**；这条线不进 OLS。

## 5. 仓位、成本、波动率目标、组合

### 5.1 收益口径（唯一定义）

对每个决策日 t（特征有效）：

```
pos_t   = 目标仓位（§4.4 × §5.3）
R[t]    = pos_t · y_cc[t] − cost_t             # 实现于 t+1 收盘
cost_t  = |pos_t − pos_{t−1}| · (fee + 0.05 / C_t)     # pos_{−1} = 0
```

- `y_cc[t] = C_{t+1}/C_t − 1`（`labels.csv`）。
- **修正 v1 的量纲错误**：v1 写"仓位收益 − 换手×(费率×N + 滑点)"，把收益率和新加坡元金额相减。
  v2 全部折成收益率口径：`fee` 是成交名义的比率，`0.05/C_t` 是 1 tick 滑点折成收益率
  （C_t ≈ 400 时 1 tick ≈ 1.25 bp）。
- 所有指标只从这一个 `R[t]` 序列计算。

### 5.2 成本

- `fee ∈ {1e-4, 2e-4, 5e-4}`（单边，名义比率），**默认 2e-4**；三档是稳健性检验 `cost3`。
- 滑点：每边 1 tick = 0.05 点 = `0.05 / C_t`。
- 换手：`Σ |Δpos|`（年化换手率在指标表里报告）。
- 不含保证金利息、税收、冲击成本；报告中列为已知局限。

### 5.3 波动率目标

- `σ̂_60,t = sd(r^full_{t−60..t−1}) × sqrt(ANN)`，取自 `full.shift(1)`，决策时已知。
- 目标年化波动 **固定 10%**，**不做验证期选择**。
  理由：Sharpe 对仓位缩放几乎不变，只有成本和 1 倍上限会造成差异，在验证集上选它是在拟合噪声，
  还白白多用一次验证集。
- `pos_t = pos_raw · min(1, 0.10 / σ̂_60,t)`，杠杆上限 1。
- `buyhold` 例外：不做缩放（§4.5）。

### 5.4 决策—执行缺口（如实承担，不回填）

- 决策在 17:00、因子截至 16:59，执行在日盘收盘（R0/R1 17:14，R2/R3 17:19）。
- 16:59 → 收盘的漂移：平均绝对值 **9.7–11.0 bp**，p95 **27.4–28.6 bp**（四时期实测）。
- 因为执行价取 `C_t`，这段漂移**不是成本**，而是"决策滞后"的真实代价，如实写进报告。
- 替代收盘口径（`C_1714`、`C_vwap_1705_1714`）已由 `labels.csv` 预置，进稳健性 `alt_close`。

### 5.5 组合层

- 数据层写成 `panels: dict[asset → daily]`，组合层等风险权重：`w_i ∝ 1/σ̂_i`，总杠杆 ≤ 1。
- 当前只有 SGP，`w = 1`，**代码不用改**；报告披露"未覆盖课程要求的多资产组合"。
- 等风险组合与 H4 假设留作扩展项。

### 7.1 随机信号对照：循环平移（circular shift）

**不能用 i.i.d. `N(0,1)`**：随机信号每天都在翻转，换手远高于真实策略，扣成本后随机分布
整体偏负，策略显得比实际好——这是对策略不利的对照。

改法：把**策略自己的仓位序列**相对收益序列做**循环平移**：

```python
for k in range(1000):
    shift = rng.integers(1, len(pos))          # 随机位移，禁止 0
    pos_k  = np.roll(pos, shift)
    R_k    = 同样的成本与波动率缩放流程，用 pos_k
```

这样保留了真实的换手水平与自相关结构，只打断信号与收益之间的对应关系。

### 7.2 类别消融

消融（去掉某一类因子）必须**连同筛选与 RFE 一起重跑**，不能只从已选好的 10 个特征里删掉那一类
——后者会让被删类别里的其他因子以"幸存"身份留下，消融不彻底。
每次消融：重跑 §4.1 外推筛选 → §4.2 筛选 → §4.3 RFE → 回测，报告指标变化。

这是**看过测试集结果之后**才加的方案，用来回答「把换手压下来会怎样」：

- 对模型打分 `z`（截断前）做**递归 EMA**：`s = λ·s_prev + (1−λ)·z`，缺失日沿用上一期；
- 用**只用训练段**的尺度系数 `k = std(z_train)/std(s_train)` 把量级调回；
- 截断到 ±1 后乘波动率目标（与主结果同口径）；
- 半衰期网格 {1,2,3,5,7,10}，**按 2023 验证期净 Sharpe 选**，测试集只跑一次 → 选出 **2 日**；
- 选参函数 `position.select_halflife` **只接受验证期一个入参**，测试期指标在选出之后才算，
  结构上不可能反向影响选择。

结果：**验证期 +0.789、测试期 +0.509**（CAGR +4.22%），测试期年换手 107.2 → **41.5**，
fee 5bp 仍有 +0.369，循环平移单侧 p = **0.051**（压线）。
**但**分年 2025 年仍为 **−1.412**，验证集只有一年（Sharpe 标准误约 1.0），
且仍跑输买入持有（+1.275 / CAGR +22.92%）。结论只能是「**降换手这个方向有效**」。

完整披露见报告 §6；边界见报告 §9.2。
